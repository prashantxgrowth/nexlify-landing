# Nexlify – Futuristic Tech Landing Page

A premium, modern landing page design for **Nexlify**, a fictional tech company focused on the convergence of human and artificial intelligence. This project features a dark futuristic aesthetic with cyan neon glows, smooth auto-sliders, interactive elements, and a clean responsive layout.

## ✨ Features

- Dark neon theme with glowing cyan accents
- Immersive hero section with bold messaging
- Full-width auto-playing service showcase slider (15 slides)
- Infinite scrolling client testimonials carousel (15 reviews)
- Interactive navigation with dropdowns and search suggestions
- Contact Us modal form with validation
- Fully responsive design (mobile + desktop)
- Built with pure HTML, CSS, and Vanilla JavaScript – no frameworks

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox, Transitions, Custom Animations)
- Vanilla JavaScript (Sliders, Modal, Interactions)
